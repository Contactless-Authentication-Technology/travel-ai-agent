Travel AI Agent Dashboard

여행 요청을 이 대시보드에서 관리하고, Chrome extension은 Booking.com 탭 안에서 실제 클릭과 입력을 수행하는 실행기 역할을 맡습니다.

Booking Agent Status
연결 대기 중
Booking.com 탭을 열어 두면 extension이 자동으로 연결됩니다.

1. 여행 요청

여행 요청을 한국어로 입력하면 표준 payload로 변환됩니다.

2. 항공편 검색

출발지와 목적지 기반으로 왕복 항공편을 검색합니다.
아직 항공편을 검색하지 않았습니다.

3. 호텔 검색

Booking.com API로 호텔을 검색합니다.
아직 호텔을 검색하지 않았습니다.

현재 요청 요약

객실 옵션

아직 객실 옵션을 불러오지 않았습니다.

마지막 실행 결과

아직 실행 결과가 없습니다.
